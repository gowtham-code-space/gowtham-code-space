## 📦 What I've Built

### 🗑️ Trash Management System
> A full civic platform for waste management. Citizens report issues. Admins route them. System tracks resolution and auto-generates compliance certificates. Real-time updates and geo-mapped issue tracking.

**Stack:** React · Vite · Tailwind · Node.js · Express · MySQL · TiDB · Socket.io · Leaflet · JWT · Cloudinary · PDFKit · Canvas · Nodemailer · Docusaurus

---

### 🎙️ SpeakMirror
> AI speech app. Audio flows through FFmpeg, gets processed by Groq AI, returns enriched text output. Built for accessibility and content creation use cases.

**Stack:** TypeScript · React · Vite · FFmpeg · Groq AI · Firebase

---

### 🏨 Hostel Management App
> Separate mobile apps for hostel managers and mess managers — a clean multi-role architecture on a single mobile codebase.

**Stack:** TypeScript · React Native · Expo

---

### 👗 Vestido

**Stack:** TypeScript · React Native · Expo · Expo Router · Supabase · Nativewind · Tailwind CSS

### 🌍 Travelz App
